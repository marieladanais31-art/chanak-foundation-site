# chanak-foundation-site

Nonprofit website for chanakfoundation.org under CHANAK TRAINUP EDUCATION, INC.

## Branch sync status

- `main`, `visual-design`, and `work` currently point to the same merge-ready commit baseline.
- The visual-design content keeps the official Chanak logo (`assets/chanak-official-logo.svg`), stronger homepage treatment, and the enhanced Mission / Impact / Programs / Donate page layouts.
- Nonprofit legal and footer disclosures remain preserved across the site pages.

## Política obligatoria de dominios

Para estas campañas se usa exclusivamente `chanakfoundation.org`. Está prohibido dirigir tráfico o configurar conversiones hacia `chanakacademy.org` o cualquiera de sus subdominios, incluido `.foundation.chanakacademy.org`. Ver [AGENTS.md](AGENTS.md). Ejecutar `python scripts/check-adgrants-domains.py` antes de publicar.
